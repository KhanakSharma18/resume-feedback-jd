# Test data

- `sample_resume_fake.pdf` / `.txt`: a made-up resume (fake person, fake contacts). Safe to publish. Use it for Normal tests.
- `sample_job_description_fullstack.txt`: a sample job post.
- `test_table_template.csv`: suggested tests for the Milestone 2 test table. The "Actual output" and "Pass / Fail" columns are
  EMPTY on purpose: run each test yourself and write what really happened. Failed tests are fine; hiding them is not.
- Add your own resumes (with permission, personal details removed) and job posts here, plus the saved outputs of each run.

Never commit a real resume that contains someone's phone number or address.
